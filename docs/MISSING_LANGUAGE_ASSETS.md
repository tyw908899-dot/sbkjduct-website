# MISSING LANGUAGE ASSETS

Current rebuild ships with a stable English-first experience to avoid mixed-language quality issues.

## Required to complete multilingual rollout
1. Approved native translations for all final pages:
   - Navigation labels, footer, CTA labels, forms, FAQs, metadata.
2. Language-specific SEO metadata:
   - Title, description, OG, Twitter, canonical/hreflang matrix.
3. Technical glossary validation per language:
   - Spiral duct, lockformer, TDF, auto duct line, seam closer, gorelocker.
4. Legal/contact localization rules:
   - Country/region formatting, phone/WhatsApp patterns.
5. QA screenshots per locale and breakpoint.
