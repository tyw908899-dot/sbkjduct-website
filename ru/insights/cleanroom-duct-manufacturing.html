Чем воздуховоды для чистых помещений отличаются от обычных

Воздуховоды ОВК чистых помещений обслуживают среду с контролируемым содержанием взвешенных частиц, где внутренняя поверхность воздуховода входит в цепочку обеспечения чистоты, а не служит просто каналом. Частицы, которые отслаиваются с внутренних поверхностей, задерживаются на неровностях соединений или возникают из-за выделения летучих веществ мастичным герметиком, напрямую влияют на класс чистого помещения. Поэтому цех, изготавливающий воздуховоды для чистых помещений, работает по иной спецификации, чем для коммерческих систем ОВК: меняются марка стали, режим сварки, чистота поверхности, герметизирующий материал, документация по качеству и полевые испытания.

Изготовление воздуховодов для чистых помещений это узкая специализация, и подходящая конфигурация станков зависит от класса ISO, марки стали и способа герметизации. В этом руководстве изложена рамка такой конфигурации.

Классы чистых помещений ISO 14644: что каждый из них означает для воздуховодов

ISO 14644-1 определяет чистоту помещения по максимально допустимому числу взвешенных частиц заданных размеров. Классы пронумерованы от 1 (самый чистый) до 9 (наименее чистый, упаковочный зал). Большинство воздуховодов ОВК для чистых помещений работает в классах с 5 по 9; классы с 1 по 4 очень специализированы и используют приточные концевые устройства с фильтрами HEPA при ограниченной протяжённости воздуховодов.

  • Класс ISO 5: фармацевтические асептические процессы, полупроводниковая литография, стерильное приготовление лекарственных форм. Воздуховоды обязательно из нержавеющей стали, непрерывная сварка TIG, электрополированная внутренняя поверхность, сварные соединения проверены на утечки по классу герметичности проекта.
  • Класс ISO 6: фармацевтический стерильный розлив, сборка современных полупроводниковых изделий, производство препаратов генной терапии. Воздуховоды из нержавеющей стали настоятельно рекомендуются, непрерывная сварка как стандарт, полированная внутренняя поверхность, класс A по SMACNA или жёстче.
  • Класс ISO 7: фармацевтические твёрдые лекарственные формы, больничные операционные, лаборатории наук о жизни. Предпочтительна нержавеющая сталь, сварные продольные швы, герметизация по классу A SMACNA.
  • Класс ISO 8: фармацевтическая упаковка, больничные послеоперационные палаты, сборка медицинских изделий. Допускается оцинкованная сталь с герметизированными соединениями; для фармацевтики предпочтительна нержавеющая сталь. Класс A по SMACNA.
  • Класс ISO 9: фармацевтический склад, больничные палаты, вспомогательные зоны лёгких чистых помещений. Стандарт оцинкованная сталь, герметизация по классу A SMACNA.

Выбор марки нержавеющей стали

Три марки нержавеющей стали охватывают подавляющее большинство воздуховодов для чистых помещений:

  • 304L: низкоуглеродистая аустенитная нержавеющая сталь, рабочая лошадка для ОВК чистых помещений классов ISO 7–9. Хорошая коррозионная стойкость, свариваемость и стоимость. 304L предпочтительнее 304, потому что меньшее содержание углерода снижает сенсибилизацию при сварке и сводит к минимуму выпадение карбидов хрома в зоне термического влияния шва.
  • 316L: низкоуглеродистая аустенитная сталь с добавкой молибдена, которую указывают для чистых помещений классов ISO 5–6, фармацевтических предприятий со стерильными процессами и любых воздуховодов, подверженных воздействию соединений хлора (прибрежные районы, некоторые стерилизующие газы). 316L стоит примерно на 15–25% дороже 304L.
  • Дуплексная сталь 2205: ферритно-аустенитная нержавеющая сталь для полупроводниковых вытяжек от мокрых процессов, где обычную аустенитную нержавеющую сталь разъедают пары кислот или растворителей. Более высокая прочность позволяет делать конструкцию из более тонкого металла.

Для некоторых специализированных полупроводниковых процессов требуются воздуховоды из стали с полипропиленовой футеровкой, стеклопластика (FRP) или ПВХ. Футеровку из PP, как правило, наносят после изготовления.

Требования к чистоте поверхности

Шероховатость поверхности Ra (среднее арифметическое отклонение профиля) это определяющая спецификация внутренней поверхности воздуховода для чистых помещений. Частицы легче прилипают к шероховатым поверхностям, и их труднее удалить при периодической влажной уборке. Типичные диапазоны чистоты поверхности по классам ISO:

  • Класс ISO 5: Ra ≤ 0,4 µm внутри, достигается нержавеющей сталью с заводской отделкой 2B плюс электрополировка
  • Класс ISO 6: Ra ≤ 0,8 µm внутри, достигается заводской отделкой 2B плюс механическая полировка или электрополировка
  • Класс ISO 7: Ra ≤ 1,6 µm внутри, достигается заводской отделкой 2B без дополнительной полировки
  • Классы ISO 8–9: Ra ≤ 3,2 µm внутри, достигается заводской отделкой 2B или 1D

Обозначения заводской отделки: 2B это холодная прокатка, отжиг, травление и дрессировка, то есть гладкая, слегка отражающая поверхность, стандартная для чистых помещений. 1D это горячая прокатка, отжиг и травление; она более матовая и шероховатая и подходит для менее строгих применений.

Конструкция соединений и швов

Воздуховоды для чистых помещений отличаются от коммерческих способом выполнения соединений и швов. Общий принцип: исключить или свести к минимуму неровности, где частицы могут отслаиваться или задерживаться.

  • Продольные швы: замковые швы Pittsburgh и защёлкивающиеся швы недопустимы для классов ISO 5–7. Применяйте непрерывную стыковую сварку (TIG), непрерывную сварку внахлёст или, для спиральных круглых воздуховодов, непрерывный закрытый замковый шов с герметизированной внутренней стороной.
  • Поперечные соединения: непрерывная сварка TIG изнутри и снаружи для классов ISO 5–6. Для класса ISO 7 допустимо герметизированное фланцевое соединение с силиконовым герметиком для чистых помещений. Для классов ISO 8–9 допускаются стандартные фланцевые соединения класса A по SMACNA.
  • Проходы: все проходы воздуховодов через стены чистых помещений сваривают или герметизируют силиконом для чистых помещений. Мастичный герметик, как правило, запрещён из-за выделения летучих веществ.
  • Подвесы: только наружные опоры, без внутренних распорок и усилений, которые могут отслаиваться частицами. Используйте шпильки и угловые кронштейны из нержавеющей стали.

Полевые испытания и приёмка

Воздуховоды для чистых помещений проходят приёмочные испытания как по герметичности, так и по чистоте. Испытание на утечки выполняют по методике испытания воздуховодов на утечку SMACNA, EN 1507 или AS/NZS 4254 в зависимости от спецификации проекта. Испытание на чистоту проводят после монтажа и до пусконаладки путём подсчёта частиц при расчётных расходах воздуха.

Для объектов классов ISO 5–6 внутреннюю поверхность воздуховода, как правило, ещё и протирают тампонами для проверки поверхностного загрязнения (TOC, общий органический углерод) и анализируют промывную воду, чтобы убедиться в отсутствии остатков технологических масел и загрязнений. Протокол обезжиривания, принятый в цехе-изготовителе, становится частью пакета документов по качеству проекта.

Конфигурация станков для изготовления воздуховодов для чистых помещений

Линия по производству нержавеющих воздуховодов чистового класса обычно включает следующие станции. Станки Taokron для формования, фланцевания и сварки составляют основу линии; электрополировка и обезжиривание это последующие процессы, которые обычно выполняют в специализированных ваннах или у субподрядчика:

  • Разматыватель нержавеющего рулона: рассчитан на массу рулона нержавеющей стали (обычно больше, чем у оцинкованной), с роликами из нержавеющей стали, чтобы не переносить загрязнения
  • Спирально-навивной станок (SBTF-1500 с комплектом для нержавеющей стали): закалённая полированная оснастка, замковый шов с герметизированной внутренней поверхностью, для круглых воздуховодов Φ80–Φ1500 мм
  • Автоматическая линия для прямоугольных воздуховодов (SBAL-III / SBAL-V): линия от рулона до фланца для прямоугольных нержавеющих воздуховодов, с полированной оснасткой
  • Станок для фланцев TDF (оснастка для нержавеющей стали): прокатывает фланец TDF прямо на нержавеющем воздуховоде; крепёж (гайки, болты, шайбы) поставляется из нержавеющей стали
  • Станция непрерывной сварки TIG: ручные и настольные аппараты TIG с защитой аргоном и водоохлаждаемой горелкой
  • Ванна электрополировки: дополнительный последующий процесс, размер рассчитан на самую крупную секцию воздуховода
  • Линия обезжиривания: ультразвуковая или щелочная очистка перед окончательной упаковкой

Технические характеристики смотрите на страницах продуктов: автоматическая линия SBAL-V, спирально-навивной станок SBTF-1500 и ручная лазерная сварка.

Пакет документов для проектов чистых помещений

Проекты чистых помещений предполагают структурированный пакет документов, поставляемый вместе с воздуховодами. Типичный пакет включает:

  1. Заводские сертификаты (mill certificates) на все использованные рулоны нержавеющей стали
  2. Записи об аттестации сварщиков (WQR) для всех сварщиков TIG, участвовавших в работе
  3. Спецификации сварочных процедур (WPS) для каждого типа сварного шва
  4. Протоколы испытаний чистоты поверхности (измерения Ra в нескольких контрольных точках)
  5. Сертификаты травления и пассивации (для изделий, требующих химической обработки поверхности)
  6. Протокол FAT (заводских приёмочных испытаний) с испытанием на утечки по классу, заданному в спецификации проекта
  7. Применённая процедура очистки и обезжиривания и сертификаты на очищающие растворы
  8. Протокол упаковки и транспортировки (упаковка в полиэтиленовые пакеты чистового класса, герметичные торцевые заглушки)

Типичные ошибки при изготовлении воздуховодов для чистых помещений

  1. Указание 304 вместо 304L. Обычная 304 сенсибилизируется при сварке TIG, что вызывает межкристаллитную коррозию в зоне термического влияния шва. Для сварных воздуховодов чистых помещений всегда указывайте марки L.
  2. Мастичный герметик на поперечных соединениях. Мастика выделяет летучие органические соединения (VOC) в воздушный поток. Используйте силикон для чистых помещений или исключите герметик непрерывной сваркой.
  3. Замковые швы Pittsburgh в классе ISO 6. Неровность шва задерживает частицы, а протереть её невозможно. Применяйте стыковую сварку или спиральные воздуховоды с закрытым швом.
  4. Оцинкованные воздуховоды в стерильных фармацевтических помещениях. Цинковое покрытие недопустимо для классов ISO 5–6, а большинство фармацевтических спецификаций распространяют это и на класс 7. Задавайте нержавеющую сталь.
  5. Пропуск обезжиривания после изготовления. Остатки формовочного масла загрязняют чистое помещение и проявляются в испытаниях на поверхностное загрязнение при сдаче. Всегда включайте щелочную очистку или ультразвуковое обезжиривание.

Вопросы и ответы

Какая нержавеющая сталь применяется для воздуховодов ОВК чистых помещений?

Если задана нержавеющая сталь: 304L для классов ISO 7–9 (оцинкованная сталь по-прежнему распространена в классах 8–9 вне фармацевтики), 316L для классов ISO 5–6 и мест с воздействием хлоридов. Для некоторых полупроводниковых вытяжек от мокрых процессов нужна дуплексная нержавеющая сталь или сталь с полипропиленовой футеровкой.

Какая чистота поверхности требуется для воздуховодов чистых помещений?

Классы ISO 5–6: Ra ≤ 0,4–0,8 µm с электрополировкой или механической полировкой. Классы ISO 7–9: Ra ≤ 1,6–3,2 µm, заводская отделка 2B.

Чем отличается герметизация воздуховодов для чистых помещений?

Поперечные соединения и продольные швы с непрерывной сваркой TIG для классов ISO 5–6. Фланцевые соединения класса A по SMACNA с силиконом для чистых помещений для класса ISO 7. Без мастичного герметика.

Могут ли станки Taokron производить воздуховоды из нержавеющей стали для чистых помещений?

Да. Спирально-навивные станки, станки для прямоугольных воздуховодов, станки для фланцев TDF и сварочные станки Taokron можно сконфигурировать с оснасткой для нержавеющей стали. Электрополировка и обезжиривание это отдельные последующие этапы.

Какой класс герметичности применяется?

Класс герметизации A по SMACNA с классом утечки 3 или жёстче, либо класс C по EN 1507, для большинства воздуховодов чистых помещений. Фармацевтические стерильные предприятия и полупроводниковые фабрики пластин часто задают более жёсткий локальный класс с непрерывной сварной конструкцией.

Какой класс герметичности применяется для воздуховодов чистых помещений?

Для чистых помещений классов ISO 5-6 воздуховоды обычно изготавливают по классу герметизации SMACNA A и испытывают на класс утечки 3 или жёстче (3 cfm на 100 sq ft при 1 in. w.g.) либо по классу C EN 1507 (около 0,17 l/s на m² при 500 Pa). Фармацевтические стерильные чистые помещения и полупроводниковые фабрики пластин часто задают более жёсткий локальный класс с непрерывной сварной конструкцией и нулевой допустимой утечкой на критичных участках воздухообработки.
