MANDATORY TRUST ASSETS

/quality/ Blueprint

Do not claim compliance, tolerance, or performance without the exact supporting certificate/report uploaded below.

Required Real Assets to Upload (Quality)

All files must be current, readable, and tied to identifiable models/serials where applicable.

  1. ISO 9001 certificate scan (full page, issuing body visible, validity dates visible).
  2. CE documents per machine family (Declaration of Conformity and supporting technical file index).
  3. Third-party audit report (latest factory/process audit summary PDF).
  4. Incoming material inspection reports (sample records with dates/spec limits/results).
  5. In-process QC check sheets (critical dimensions or checkpoints signed by inspector).
  6. Final acceptance test (FAT) reports (machine model + serial + measured results).
  7. Calibration certificates (measurement tools used in QC, with expiry dates).
  8. Welding/NDT test records where relevant to machine fabrication.
  9. Customer SAT or commissioning sign-off (redacted if needed, but authentic and dated).
  10. Traceability example pack (PO → production record → FAT → shipment linkage).

Asset File Naming (Required)

  • quality-iso9001-YYYY-YYYY.pdf
  • quality-ce-sbtf1500-DoC.pdf
  • quality-fat-model-serial-YYYYMMDD.pdf
  • quality-calibration-toolid-YYYYMMDD.pdf
  • quality-traceability-pack-YYYYMMDD.pdf
